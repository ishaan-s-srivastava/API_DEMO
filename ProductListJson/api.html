About This API

I chose PokeAPI because it is free and provides information about Pokemon. It returns JSON data and does not require an API key. Also, I'm a really big Pokemon fan.

API source: PokeAPI Documentation

The API uses a Pokemon name as a parameter in the URL. I used "dialga" to retrieve information about Dialga, my favorite Pokemon.

This API could be used to create a Pokemon website that displays information about different Pokemon.
